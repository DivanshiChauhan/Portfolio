# Portfolio Website

This is a personal portfolio website built using **React.js**, **Tailwind CSS**, and **Framer Motion** to showcase projects, skills, and experience.

## 🔥 Features
- **Fully Responsive**: Works seamlessly on all devices.
- **Framer Motion Animations**: Smooth animations for better UI experience.
- **Dark-Themed Design**: Elegant black and grey-themed layout with pink highlights.
- **Project Showcase**: Displays all personal projects with descriptions and GitHub links.
- **Experience Section**: Lists past work experience and technologies used.
- **Contact Form**: Simple and easy-to-use contact form.

## 🛠️ Tech Stack
- **Frontend**: React.js, Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Deployment**: Hosted on GitHub Pages

## 🚀 Getting Started
1. Clone the repository:
   ```sh
   git clone https://github.com/DivanshiChauhan/Portfolio.git
   ```
2. Navigate to the project folder:
   ```sh
   cd Portfolio
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Start the development server:
   ```sh
   npm run dev
   ```
